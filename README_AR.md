# Labib Prompter AI — النسخة الأولية 0.1

## ما الموجود في هذه النسخة؟
- واجهة Android عربية.
- إدخال النص وعرضه.
- طلب إذن الميكروفون.
- استقبال نتائج التعرف الصوتي الجزئية والنهائية.
- مطابقة تقريبية للكلمات مع النص.
- تلوين الكلمات التي تم الوصول إليها وإبراز الكلمة التالية.
- الاحتفاظ بآخر موضع معروف عند اكتشاف كلام لا يطابق النص.

## ما الذي لم يكتمل بعد؟
هذه نسخة تأسيسية وليست المنتج النهائي:
- لم يتم ربط نموذج ذكاء اصطناعي سحابي لفهم معنى الارتجال.
- اكتشاف الارتجال هنا أولي ويعتمد على عدم تطابق الكلمات، وليس فهماً دلالياً كاملاً.
- التعرف الصوتي يعتمد على خدمة الكلام المتاحة في الهاتف. `EXTRA_PREFER_OFFLINE` مجرد تفضيل، ولا يضمن أن اللغة تعمل دون إنترنت.
- لم يتم اختبار المشروع على جهاز فعلي بعد.
- لا يوجد APK مبني ضمن هذه الحزمة.

## البناء باستخدام Android Studio
1. افتح Android Studio على كمبيوتر.
2. اختر Open وافتح مجلد `LabibPrompterAI`.
3. انتظر مزامنة Gradle وتثبيت Android SDK 35 إذا طلبه البرنامج.
4. وصّل الهاتف وفعّل USB debugging، أو استخدم المحاكي.
5. اضغط Run لتثبيت التطبيق.

المتطلبات: Android Studio حديث وJDK 17. الحد الأدنى للتطبيق Android 10 (API 29).

## الخطوة التالية
إضافة محرك مطابقة أفضل للعربية، وتمييز الارتجال عن القراءة، ثم ربط واجهة API آمنة لتحليل السياق. لا تضع مفتاح API سرياً داخل تطبيق Android؛ يجب أن يمر عبر خادم وسيط.
